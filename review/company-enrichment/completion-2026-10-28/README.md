# 企业资料全量核查（2026-10-28）

本轮检查全部 3,814 家企业，完成 7,790 条补充检索。只补入主体和所在地能够核对的公开资料；无可靠证据的字段保持空白。未增加、删除或重排企业，全部历史排名文件和企业注册表均与本轮开始时的 SHA-256 相同。

本轮涉及 422 家企业：新增 126 个官网关联、10 个其他官网、220 个 Logo、32 个 Alibaba 店铺及店铺地址、83 个公开地址、22 项注册资金、8 项主营产品。新增官网中包含替换此前错误关联的结果，并非全部为净新增。

同时撤销 127 条错误或失效链接及 17 个错误图标关联，包括第三方新闻/目录、错主体、404 店铺，以及用户明确要求不采用的候选。所有企业档案和原有其他资料保留。另将 3 个已有网站明确标为关联企业网站。

目前共有 802 家登记官网、577 家使用已核实 Logo、116 家登记 Alibaba 国际站。其余缺项不代表企业没有网站或店铺，只代表本轮没有取得可确认的公开资料。

- `企业资料全量清单.csv`：全部企业当前资料与缺项。
- `企业资料仍缺项.csv`：仍有未取得可确认资料的字段。
- `企业资料待确认.csv` / `pending-confirmations.json`：51 项合理候选及具体疑问，等待用户确认，尚未公开采用。
- `changes.json` / `corrections.json`：逐项新增、纠正记录。
- `verified-sources.json`：采纳资料的来源、主体证据和页面摘要。
- `ranking-integrity.json`：原始注册表与全部排名文件的哈希校验。

CSV 使用 UTF-8 BOM 编码，可直接用 Excel 打开。网页未加入任何内部核查文案。注册资金与地址保留各自来源口径，关联企业、店铺地址不冒充榜单企业的注册信息。
