# 未登记官网企业复查：2026-10-28

本轮从提交 cdfd3ee 出发，复查全部 3,012 家未登记官网企业，完成 6,805 条有效补充查询。查询服务错误已经重试或换用公开搜索来源，未将服务错误记为“未找到”。

本轮为 61 家首次补入官网，另补 4 个其他官网；增加 13 个 Alibaba 店铺、56 个 Logo、58 个公开联系/登记地址、23 个官网经营地址、57 项注册资金和 23 项主营产品，合计更新 133 家企业。部分此前已有店铺的企业增加了店铺公开地址，新增店铺地址共 14 项。

公司官网采用全称、公开英文名称、版权主体与乐清/温州地址等证据核对。企业资料中的网站字段只作为发现线索，第三方招聘、新闻、目录、证书查询及行业平台没有作为企业官网登记。厂商网页混用公司资料、建站商子域名、不同法人主体等存疑情况列入待确认清单，尚未公开采用。

名山进出口和永固进出口的网站由页面明确列出的出口业务部门/销售公司关系确认，公开标为关联企业网站；相关集团地址没有冒充本企业注册地址。Logo 来自企业网站或已核实的店铺，已逐张检查，剔除了客服插图、语言图标及产品宣传图。朗高的品牌图片来源暂时无法正常读取，保留文字占位。莫得进出口的官网主体已确认，但 TENGEN 品牌图标关联仍待确认，保留文字。

全部 3,814 家企业、原有企业名称、全部周期和原始名次均未改变。原有档案字段、链接及已核实 Logo 保留；本轮只增加资料。14 个注册表/周期/排名文件逐一比较 SHA-256，全部相同。

当前登记官网共 863 家，仍有 2,951 家未取得可确认的官网，不能据此认定企业没有网站。

- `企业资料待确认.csv` / `pending-confirmations.json`：60 项网站、集团关系或图标候选，包含上一轮未解决项，等待确认。
